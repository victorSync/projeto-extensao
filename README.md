# Sistema de Cadastro e Controle de Atendimentos

Projeto desenvolvido para a Extensão Curricularizada do curso de Análise e Desenvolvimento de Sistemas (ADS).

## Objetivo

Desenvolver um sistema web simples para organizar o cadastro de pessoas, o registro de atendimentos e a consulta de informações.

## Funcionalidades

- Cadastro de pessoas
- Consulta de pessoas cadastradas
- Registro de atendimentos
- Histórico de atendimentos
- Dashboard com indicadores básicos

## Tecnologias utilizadas

- Python
- Flask
- HTML
- CSS
- SQLite

## Estrutura do projeto

- `app.py` — aplicação principal em Flask
- `database.py` — criação e configuração do banco de dados
- `database.db` — banco de dados SQLite utilizado nos testes
- `templates/` — páginas HTML do sistema
- `static/` — arquivos de estilo CSS
- `EVIDENCIAS/` — imagens utilizadas como evidências do desenvolvimento
- `requirements.txt` — dependências do projeto

## Projeto acadêmico

Este sistema foi desenvolvido como um MVP (Produto Mínimo Viável), com o objetivo de demonstrar a aplicação de conhecimentos de desenvolvimento web, banco de dados e organização de informações.

Os dados utilizados no protótipo são dados fictícios para fins de teste e demonstração.
